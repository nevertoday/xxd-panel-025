# XXD Panel 025｜格式塔正负形莫兰迪丝网版画生成核心

只处理当前任务明确提供的一张源照片。锁定一个主体或不可拆分关系、主要动作，以及至少三个源图专属线索；再从同一照片提炼一个与主体关系最紧密的环境、结构、物件或象征意象。不得借用样张、旧成品或其他输入的隐藏意象、色板、文案与构图。

## 一眼主体，第二眼隐藏意象

保留主体最具辨识度的清晰外轮廓，让隐藏意象通过轮廓咬合、负形镂空、边界共用和图底反转进入同一个完整图形。远看必须先识别主体，近看才发现另一层场景或意象；一个形状的边缘必须自然成为另一个形状的边界。

禁止把两个对象并列、叠放、透明混合、双重曝光或用两个独立图标拼成“错视”。隐藏层必须来自源图事实或有依据的象征关系，并且不破坏第一层主体识别。

## 单一锚点与留白转换

只保留一个视觉锚点、一个主轮廓和大面积浅色纸面。根据主体姿态、朝向、重心与轮廓走势决定偏心、局部裁切、上下嵌套或边缘对齐。辅助元素极少，趣味来自第一次看见与再次看见之间的瞬间切换，而不是装饰数量。

拒绝多个并列焦点、复杂场景、平均铺满、直接拼贴、图标阵列、解释性箭头与模板居中。

## 2–4 色莫兰迪粉彩

从源图最有精神的颜色关系提取并柔化为 2–4 种莫兰迪粉彩：雾粉、柔杏、灰绿、鼠尾草、淡陶土、奶油黄、雾蓝、灰紫或其他受源图支持的低饱和综合色。以浅色纸面为底，通过综合色温、明度差和面积比例建立层次。

颜色必须干净、柔和、有空气感，拒绝脏灰、沉重做旧、荧光色、高反差商业色、彩虹色、固定色板和渐变。

## 清晰平面与真实丝网触感

图形边缘清晰、色块平整，保留轻微纸张纤维、丝网印刷颗粒、油墨覆盖和小幅套色偏差。物理印刷痕迹必须克制，不得成为廉价脏污滤镜。禁止渐变、数字模糊、写实阴影、3D体积、光滑CG、厚涂和过度破损。

## 025 文字系统

自动文案从源图有依据的身份、地点、动作、情绪、状态或象征意义中提炼一个简短标题，并按需加入极少地点、编号、状态词或微型注释。地点、日期、出处与事实编号必须由用户提供或可靠确认，不得伪造。

文字沿主体轮廓、负形边界、水平基线或留白轴线排布，也可局部嵌入图形、被轮廓切断或与色块发生遮挡，使它成为正负形结构的一部分。使用目标语言自然的小尺度高级编辑排版，不把拉丁宽字距、旋转或切词机械套用到其他文字系统。准确用户文案逐字保留；无文字模式不出现文字或伪文字。

## 模式与硬性验收

严格服从附加的 `OUTPUT MODE`、`FINAL SIZE` 与 `DESIGN FRAME`。双联模式只生成设计半幅；纯设计与壁纸不显示原照片。每张壁纸按设备重新构图，不裁切其他设备成果，不绘制系统 UI 或设备模型。连贯壁纸共同参考原照片与同一张已批准定调图，绝不串联衍生图。

硬性验收：一个源图绑定的清晰主体轮廓；一个同源或有依据的隐藏环境／结构／物件／象征意象；二者通过轮廓咬合、负形镂空、边界共用与图底反转成为单一图形；远看先见主体、近看再见隐藏层；一个视觉锚点与大面积留白；2–4 种源图派生莫兰迪粉彩；清晰平面色块＋轻微纸纤维、丝网颗粒、油墨覆盖和套色偏差；文字进入轮廓、负形或留白轴；无并列双图、透明叠放、双重曝光、多焦点、复杂插画、渐变、写实阴影、3D、卡通、商业宣传或伪文字。

若任一硬性条件失败，纠正生成资产，不要用程序绘图、SVG、HTML、Canvas 或后期文字覆盖伪造成品。
