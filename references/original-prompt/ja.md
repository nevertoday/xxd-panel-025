# XXD Panel 025 原始プロンプト · 日本語訳

> 閲覧用の忠実な翻訳です。実行時の唯一の基準は[簡体字中国語の原文](zh-CN.md)です。

アップロードした各写真を、それぞれ1枚の独立したハイエンドなデザインポスターにしてください。複数画像を組み合わせず、各写真を個別に出力します。全体は3:4の縦構図を採用し、上下2つの領域の高さは厳密に1:1とし、それぞれ画面の50%を占めます。

上半分には元の写真を残し、被写体の構造、リアルな質感、自然な光と影、元の色彩の雰囲気を維持し、わずかにハイエンドな写真のカラーグレーディングのみを施して、アート雑誌、インディペンデント出版物、展覧会写真のような質感を持たせます。画面比率に合わせるため、空、地面、または周囲の背景を自然に拡張できますが、被写体を引き伸ばしたり、歪めたり、変更したりしてはいけません。

下半分では、写真の中で最も識別性の高い**被写体、輪郭、姿勢、物語上の関係性**を抽出し、ミニマルなゲシュタルトのポジ・ネガ形によるシルクスクリーン版画として再構成します。被写体の最も識別性の高い外輪郭を残すと同時に、元画像からそれと最も密接な関係を持つ環境、構造、物体、または象徴的イメージを1つ抽出し、両者を**輪郭のかみ合わせ、ネガ形の切り抜き、境界の共有、図と地の反転**によって1つの完全な図形へ融合させます。遠くからはまず被写体を認識し、近くで見て初めて、もう1つの場面やイメージがその中に隠れていることに気づくようにします。2つの対象を単純に重ねるのではなく、一方の形の縁が自然にもう一方の形の境界となるようにします。

構図は**単一の視覚的アンカー、明確なシルエット、大きな余白**を保ち、被写体自体の姿勢、向き、重心、輪郭の流れに応じて配置を決めます。偏心配置、部分的な裁ち落とし、上下の入れ子、または縁の整列を採用し、ポジ形とネガ形の間に巧妙な視覚的転換を生み出すことができます。補助要素は極めて少なくし、視覚的な面白さが複雑な装飾ではなく、「何が見えるか」と「もう一度見ると何が見えるか」が瞬時に切り替わることから主に生まれるようにします。

配色には、癒やしを感じさせ、柔らかく上質な**モランディ・パステル体系**を採用し、夢のような建築空間における低彩度の配色ロジックを参照します。ミストピンク、ソフトアプリコット、グレイッシュグリーン、セージ、淡いテラコッタ、クリームイエロー、ミストブルー、グレイッシュパープルなどを互いに調和させ、明るい色の紙面をベースに、元の写真から最も生気のある色彩関係を選んで柔らかく再編します。全体を2～4色に抑え、総合的な色温度、明度差、面積比によって階層を作ります。色はクリーンで柔らかく、空気感を持たせ、濁った灰色、重苦しいエイジング、蛍光色、高コントラストな商業的配色は避けます。

わずかな紙の繊維、シルクスクリーン印刷の粒子、インクの被覆、版ずれを残し、図形に本物の版画の触感を持たせますが、縁は明確に、色面は平坦に保ちます。グラデーション、3Dの立体感、写実的な影、滑らかなCGの質感は使用しません。

文字もポジ・ネガ形の構図に参加させます。写真の**アイデンティティ、場所、動作、感情、状態、または象徴的意味**から短いタイトルを抽出し、ごく少量の場所、番号、状態語、または極小の注釈を組み合わせます。文字は被写体の輪郭、ネガ形の境界、水平のベースライン、または余白の軸線に沿って配置でき、部分的に図形へ埋め込んだり、輪郭で分断したり、色面と重ねて遮蔽したりすることもできます。文字が後から貼り付けたタイトルではなく、版画構造の一部のように見えるようにします。全体として小さく、抑制され、知的で、上質なエディトリアル感を保ちます。

全体として、**ミニマルな幾何学、ゲシュタルト錯視、柔らかなモランディカラー、シルクスクリーン版画、詩的な物語性**を組み合わせた視覚的気質を表現します。被写体が人物、動物、植物、建築、器物、乗り物、自然景観のいずれであっても、「一目で被写体を認識し、二度目に隠されたイメージを発見する」という二重の読解体験を保ち、複数の並列した焦点、直接的なコラージュ、複雑なイラスト、カートゥーン感、商業宣伝感、テンプレート感を避けます。
